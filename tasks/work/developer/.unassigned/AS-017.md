# Implement isolated test foundation

## Objective

Implement reusable test fixtures and a deterministic loopback model API provider. Adopt relevant upstream test code and preserve license notices.

## Acceptance criteria

- [ ] Default pytest runs without harnesses, model credentials, GPU or local model.
- [ ] Provide fake executables, adapter, clock, temporary homes, synthetic session fixtures and worker cleanup.
- [ ] Implement and test the required mock API protocols, including streaming, tool calls and errors.
- [ ] Provide native test isolation with non-loopback egress denial, and verify it before launching clients.
- [ ] Add pinned provisioning helpers and an explicit native-test entry point. Do not require local tools.
- [ ] Document requirement-to-test mapping and coverage commands. Keep test code out of the product distribution.

## Execution

Record commit, test commands, results and limitations.
