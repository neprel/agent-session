# Implement shared delivery and tmux fallback

## Objective

Implement shared delivery in delivery.py, tmux fallback in tmux.py and message in commands/message.py. Use the Harness interface for native delivery and probe.

## Acceptance criteria

- [ ] Preserve Unicode and multiline stdin.
- [ ] Accept optional `--from PATH` and resolve it to the absolute sender registration path.
- [ ] Deliver the sender envelope through each transport; preserve the original text, including multiline and Unicode content.
- [ ] Send unchanged text when `--from` is absent.
- [ ] Verify reply routing from a different working directory.
- [ ] Accept a valid offline sender. Reject invalid sender targets before delivery.
- [ ] Do not duplicate uncertain delivery or contact inactive harness.
- [ ] Reject stale pane or unsafe approval state.
- [ ] Mock transport tests pass.

- [ ] No concrete harness imports in shared delivery or command code.

- [ ] Add unit and synthetic integration tests for all requirements implemented by this task. Use the isolated test foundation in AS-017. Do not require real harnesses or inference for these tests.
